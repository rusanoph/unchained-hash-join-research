# Attribution and packaging

Local research scripts and worker code use the bundled MIT license. The archived JOB statements are the Join Order Benchmark by Leis et al., also distributed in the [pinned Apache DataFusion IMDb benchmark suite](https://github.com/apache/datafusion/tree/2f6c665fef63936f08a4aa7a4fb01b87a4d2b009/benchmarks/queries/imdb). All 113 statements were checked against that suite at the SQL token level. The code diff from Matt Butrovich’s [review](https://github.com/apache/datafusion/pull/27746#discussion_r4698342517) is preserved byte-for-byte with its source references under the bundled Apache-2.0 license. Apache source attribution is in [Apache NOTICE](NOTICE-APACHE).

SNAP, CWI IMDb and TPC-H input files are obtained separately under their providers' terms. The bundle contains their identity receipts, SQL, generated diagnostic cases and measurements. Published JOB result records use SHA-256 of the exact result rows to support cross-arm equality. The original worker fingerprints and archived verification counts are preserved. The portable verifier checks the recorded JOB cross-check coverage. Repeating the comparison to the older native outputs requires the historical reference archive.

Machine-local paths and the host name were replaced with public placeholders. Plan text hashes and references were updated together. Timing samples, seeds, executable digests, query coverage and published statistics retain their recorded values. Build receipts document executables used for measurement. Producing bit-identical executables from a fresh build depends on the toolchain and build paths.
